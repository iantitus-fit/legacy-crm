# Sprint 14.5: Dashboard UX + Navigation Labels — Implementation Plan

**Goal:** Ship 7 UX features from client tester feedback: dashboard task rows, global FAB, pipeline button labels, estimate list create button, responsive estimate detail, estimate name/header metadata + migration, and clickable tel/maps links globally.

**Architecture:** One backend migration (0017) adding `estimates.expiration_date`, `estimates.created_by_user_id`, `contacts.company`. Backend schema/router updates. Dashboard stats endpoint extension. Several new reusable frontend components (FAB, JobPickerModal, QuickCreate modals, DashboardTaskSection, PhoneLink, AddressLink). Edits to existing list, detail, and pipeline pages.

**Tech Stack:** FastAPI, SQLAlchemy 2.x, Alembic, React 18, Tailwind, lucide-react, react-router-dom.

**Spec:** `docs/superpowers/specs/2026-04-11-sprint14.5-dashboard-ux-design.md`

## Notes for the Implementer

- Use `docker-compose run --rm backend alembic upgrade head` to apply the migration locally; it's also auto-applied by FastAPI lifespan.
- FastAPI model module order matters for SQLAlchemy relationships — if you hit `NoForeignKeysError` when adding the `created_by_user_id` FK, ensure the User model is imported before Estimate in `app/models/__init__.py`.
- The `JobPickerModal` uses `listJobs` which accepts `search` and `perPage` params — check `frontend/src/api/jobs.js` to confirm the signature.
- DO NOT break the existing `tasks_due_today` / `tasks_due_this_week` dashboard fields or test_dashboard tests.
- The 1 pre-existing flaky test (`test_dashboard_tasks_due_this_week`) only fails on Saturdays — if today is a Saturday, accept the single failure as expected.
